# Go bug and security checklist

Severity: crit > high > med > low. Each entry lists the static pattern and
the confirmation oracle. Run `gosec`, `go vet`, `go test -race`,
`govulncheck` alongside the scanners.

## Injection and input handling

- `exec.Command("sh", "-c", ...)` or `exec.Command` with `+`/`fmt.Sprintf`
  concatenation (gosec G204, crit). Oracle: inject `;id` or `$(id)` and show
  it executes.
- `db.Query/Exec/QueryRow` built with `fmt.Sprintf` or `+` (high). Oracle:
  `' OR 1=1--` survives to the wire. Fix: parameterized args.
- `http.Get/Post` with concatenated or request-derived URL (gosec G107,
  SSRF, high). Check redirects are bounded and the host is allowlisted.
- `filepath.Join(base, userInput)` reaching `os.Open`/`os.Create` (G304,
  path traversal). Oracle: `..` segments escape the base. Fix:
  `filepath.Rel` plus prefix check, or `fs.FS` jails.
- `text/template` for HTML output, or `template.HTML(x)` casts on
  untrusted data (G203, high). Fix: `html/template`.
- `unsafe.Pointer` / `unsafe.Slice` anywhere (G103). Every use needs a
  written justification.
- Open redirects: `Header().Set("Location", userVar)` or `http.Redirect`
  built from request fields.
- `yaml.Unmarshal` into structs with broad or interface fields from
  untrusted input.
- `strconv.Atoi` results feeding `make([]T, n)` or slice indexes without
  bounds checks (integer overflow to giant alloc, G602).

## Concurrency and lifecycle

- Loop variable capture: `go func() { ... v ... }()` inside a `for` without
  passing `v` as a parameter. Safe-looking post-1.22 code still shares
  captured pointers; confirm with `-race` or a print-order test.
- `defer` inside a `for` loop: resources held until function return, not
  iteration end. Fix: wrap the body in a function or close explicitly.
- `wg.Add` inside the goroutine it is meant to track: `Wait` can return
  before the Add runs.
- `close(ch)` with a later `ch <-` or a second `close(ch)`: panic.
- Package-level `var m = map[...]` or slices mutated in files that spawn
  goroutines without a `sync.Mutex`/`RWMutex`: race under load.
- `http.Response` body never closed: connection and goroutine leak.
- Goroutines blocked on send to a channel nobody reads, or on
  `<-ctx.Done()` when ctx is never cancelled: leak. Confirm by counting
  goroutines before and after a burst.
- `errgroup`/`sync.Map` misuse: writing to a `sync.Map` key while
  iterating it is fine, but plain maps are not.
- `select` with a `default` branch in a loop: busy spin.
- Errors lost inside goroutines: the error is assigned to a variable the
  caller never reads.

## Crypto and TLS

- `crypto/md5`, `crypto/sha1`, `crypto/des`, `crypto/rc4` imports (G401,
  G501-G505). Exceptions: md5 for non-security checksums, still flag.
- `math/rand` anywhere near tokens, keys, nonces, session IDs (G404).
  Fix: `crypto/rand` or `math/rand/v2` only for non-security use.
- `InsecureSkipVerify: true` (G402, high). No exceptions in shipped code.
- `MinVersion` below TLS 1.2 (G402).
- `==` comparing MACs, signatures, tokens or password hashes: timing
  oracle. Fix: `hmac.Equal` / `subtle.ConstantTimeCompare`.
- `fmt.Errorf("...%v", err)` where callers need `errors.Is/As`: use `%w`.
- JWT: verification without pinning `algorithms`, or accepting `none`.
- ECB mode: `NewECBEncrypter`/`NewECBDecrypter`.
- Hardcoded keys, IVs, salts or signing secrets in source.

## Error handling and logic

- `_ = f()` or `f()` where the error is dropped on a path that later
  trusts the result.
- `nil` map writes panic: `var m map[K]V` then `m[k] = v` without make.
- Slice aliasing: appending to a shared backing array mutates a sibling
  slice.
- `time.Tick` in long-lived code leaks the underlying ticker; use
  `time.NewTicker` + `Stop`.
- Shadowed `err` in inner scopes hiding the real failure.
- `panic` in library code paths reachable from untrusted input: DoS.

## Testing weaknesses

- Tests asserting only "no panic" or calling `t.Log` instead of
  `t.Error`/`require`.
- Golden files regenerated by default (`-update` flags committed).
- `go test -race` not exercised in CI; races found under stress count.
